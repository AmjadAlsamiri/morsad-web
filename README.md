مِرْصاد ويب — Mirsad Web
=========================

نظرة عامة
---------
منصة دفاعية لتقييم إعدادات أمن مواقع الويب التي يملك المستخدم تصريحًا صريحًا لفحصها، مع سجل محلي وتقارير PDF.

تشغيل المشروع محليًا
--------------------
1. أنشئ بيئة افتراضية (موصى به):
   python -m venv venv
   venv\Scripts\activate
2. ثبّت الاعتمادات:
   pip install -r requirements.txt
3. شغّل الخادم:
   python run.py
4. افتح المتصفح عبر: http://127.0.0.1:5000

المزايا
------
- فحص رؤوس الحماية، HTTPS، TLS، DNS، الكوكيز، robots.txt وsitemap.xml وsecurity.txt.
- تحليل إضافي لجودة CSP وCORS وSameSite، ومدة صلاحية TLS وحجم مفتاحها عند توفره.
- تقييم درجة الأمان ومستوى الخطورة مع توصيات قابلة للتنفيذ.
- حفظ نتائج الفحص في قاعدة SQLite محلية وعرض آخر الفحوصات.
- تنزيل تقرير PDF بالاعتماد على التقرير المحفوظ، لا بيانات يرسلها المتصفح.
- رفض العناوين المحلية والخاصة والمنافذ غير القياسية، وفحص إعادة التوجيه قبل اتباعها.

حدود الفحص
----------
لا ينفذ المشروع استغلال ثغرات أو تخمين كلمات مرور أو مسح منافذ. يجب تحديد مربع التأكيد قبل بدء أي فحص، ولا ينبغي استعماله إلا على المواقع المملوكة أو المصرح بها.

اختبار دون اتصال شبكي
---------------------
يتضمن المجلد tests اختبارات وحدية تستخدم mocking لتشغيل اختبارات التحليل دون الاعتماد على الشبكة.

ملاحظات
-------
- بيانات التطوير المحلية تحفظ في `instance/mirsad.sqlite` ولا يجب رفعها إلى مستودع عام.
- يفضل تعيين `MIRSAD_SECRET_KEY` قبل أي نشر، وتشغيل الخادم خلف WSGI إنتاجي بدل خادم Flask التطويري.
