# مرصاد ويب: وثيقة موجز أكاديمي

## 1. فكرة المشروع

مرصاد ويب منصة ويب دفاعية لتقييم إعدادات أمن المواقع المصرح بفحصها. تترجم المنصة نتائج تقنية متفرقة إلى درجة أمنية، مستوى خطورة، وتوصيات عملية باللغة العربية، مع تقرير قابل للتنزيل.

## 2. المشكلة

تفتقر كثير من المواقع الصغيرة والناشئة إلى وسيلة مبسطة لفهم أثر الإعدادات الأمنية الأساسية، مثل HTTPS ورؤوس الحماية وخصائص ملفات الارتباط. الأدوات الاحترافية قد تكون معقدة أو تقدم نتائج تقنية فقط دون توجيه مناسب للمستخدم العربي.

## 3. أهداف المشروع

1. بناء منصة عربية سهلة الاستخدام لفحص إعدادات أمن الويب الأساسية.
2. تقديم فحوصات دفاعية غير تدخّلية للمواقع المملوكة أو المصرح بها فقط.
3. احتساب درجة أمنية ومستوى خطورة قابلين للفهم.
4. تحويل النتائج إلى توصيات عملية وتقرير PDF عربي.
5. حفظ سجل محلي للفحوصات لمتابعة التحسن مع الزمن.
6. مقارنة الفحوصات المتتابعة للموقع نفسه لإظهار التحسن أو التراجع في الإعدادات المقاسة.

## 4. نطاق الإصدار الحالي

يفحص النظام HTTPS والتحويل إليه، شهادة TLS وعمرها وحجم مفتاحها، رؤوس الحماية، جودة CSP وCORS، خصائص ملفات الارتباط، DNS، وملفات `robots.txt` و`sitemap.xml` و`security.txt`، إضافة إلى مؤشرات محدودة لمسارات الإدارة ومعلومات الخادم.

لا ينفذ النظام استغلال ثغرات أو تخمين كلمات مرور أو مسح منافذ أو زحفًا واسعًا. ويمنع عناوين الشبكات الداخلية والخاصة والمنافذ غير القياسية، ويعيد التحقق من وجهة كل إعادة توجيه.

## 5. المنهجية

1. إدخال المستخدم رابطًا وتأكيد امتلاك التصريح.
2. التحقق من صحة الهدف ومن كونه عنوانًا عامًا آمنًا للفحص.
3. تنفيذ وحدات التحليل بقراءات HTTP/HTTPS محدودة.
4. تجميع النتائج واحتساب الدرجة ومستوى الخطورة.
5. عرض التقرير، حفظه محليًا، وإتاحته بصيغة PDF.
6. مقارنة التقرير الحالي بالسابق عند وجود فحصين أو أكثر للهدف نفسه.

## 6. معايير التقييم المقترحة

- صحة اكتشاف رؤوس الحماية وHTTPS باستخدام مواقع اختبار أو استجابات محاكية.
- صحة رفض العناوين المحلية والخاصة وإعادات التوجيه غير الآمنة.
- وضوح واجهة الاستخدام والتقرير العربي وفق تقييم عينة من المستخدمين.
- نجاح حالات الاختبار للوحدات والمسارات الأساسية.
- زمن الاستجابة للفحوصات ضمن نطاق مقبول في بيئة اتصال عادية.

## 7. التطوير المستقبلي

إضافة حسابات مستخدمين وصلاحيات، جدولة الفحوصات، رسوم بيانية تاريخية، عامل مهام غير متزامن للفحوصات الطويلة، وتحسين محرك التقييم وفق معايير OWASP.
